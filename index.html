Privacy Policy — Soccer Run

Last updated: 24 October 2026

Soccer Run does not collect, store, or share any personal data. It has no accounts, no advertising, no analytics, and no internet access.

What the app collects

Nothing. Soccer Run does not collect, transmit, or sell any personal information.

The app does not request internet access. It has no INTERNET permission, which means it is technically incapable of sending data anywhere, including to the developer.

There is no sign-up, no login, and no user account of any kind.

What is stored on your device

Soccer Run saves a small amount of information locally on your phone so the game remembers your progress between sessions:

  • Your best score
  • The furthest level you have reached
  • Your settings for music, crowd sound, and vibration

This information never leaves your device. It is stored using Android's standard app storage and is deleted automatically when you uninstall the app. The developer cannot see it.

Third-party services

Soccer Run contains no advertising networks, no analytics services, no crash reporting, no social network integrations, and no in-app purchases. No third-party code collects information from this app.

Permissions

Soccer Run requests a single permission that affects you:

  • Vibrate — used to provide a short buzz when you lose the ball or score a goal. It can be switched off in the game's Settings screen. This permission cannot access any information.

The app also declares one internal, self-signed permission that Android's own support libraries add automatically (DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION). It exists only to stop other apps on the device talking to this one, grants Soccer Run no access to anything, and is never shown to you.

The app does not request internet, location, camera, microphone, contacts, storage, or device identifier permissions.

Children

Soccer Run is suitable for all ages. Because the app collects no data whatsoever, it collects no data from children either.

Changes to this policy

If this policy changes, the revised version will be published at this address with an updated date above. Since the app collects no data, any future change would most likely relate to new features rather than data practices.

Contact

If you have any question about this policy, please contact soccerrun.dev@gmail.com.
